#列出所有API资源 即如 nodes pods namespaces 等所有资源的名字
kubectl api-resources 

东西都叫资源 Resource，创建容器的yaml文件使用，yaml里的字段 kind 

Namespace                 # 命名空间
node                      # 物理机或虚拟机

Pod                       # 一个或多个容器组成的容器组，容器间资源共享
Deployment                # 更好部署Pod，如增加副本选项
ReplicaSet                # 更好部署Pod
daemonsets                # 用于实现每个node运行一个pod，如日志收集

PersistentVolume          # pvc使用pv存储 
PersistentVolumeClaim     # 首先需要创建一个PV，并将其分配给PVC，之后再将PVC分配给应用程序使用，一个PV可以被多个PVC使用，一个PVC只能请求一个PV
StorageClass              # pvc设置使用StorageClass，无需先创建pv

Endpoints                 # 可以把外部的链接到k8s系统中。创建Endpoints绑定外部资源，然后Service绑定Endpoints。
Service                   # 部署一个内部虚拟IP，其他deployment可以链接。
Ingress                   # 使用ingress实现反向代理  需要先安装相应controller，如traefik

ConfigMap                 # 存储配置信息，让镜像 和 应用的配置文件解耦
Secrets                   # 用于存储和管理一些敏感数据，比如密码，token，密钥等敏感信息。类似于ConfigMap，但这个的存储是base64转换。


CRD Custom Resource Definition 用户自定义资源
crd也是通过yaml安装

kubectl get crd -A
